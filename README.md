# 🏁 Garagem dos Sertões

Site não oficial, feito por fã, com o perfil de cada equipe e cada veículo do Rally dos Sertões 2026: fotos reais, história, piloto e navegador, e o resultado oficial de cada etapa direto da cronometragem.

🔗 [garagemsertao.vercel.app](https://garagemsertao.vercel.app)

## O que tem

- Perfil de equipe e de veículo, com fotos e histórico reais (sem dado inventado)
- Resultado oficial por etapa, puxado da cronometragem do rally
- Cadastro e edição sem login: cada equipe reivindica seu perfil com um código de edição
- PWA instalável, funciona bem em conexão ruim

## Stack

React + Vite + TypeScript + Tailwind, Supabase (banco, storage, RPCs com Row Level Security), deploy na Vercel.

## Sobre

Construído sozinho, do modelo de dados ao deploy, com o Claude Code guiando o desenvolvimento de ponta a ponta. Não tem vínculo com a organização do Rally dos Sertões nem com as equipes.
